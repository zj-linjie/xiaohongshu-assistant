# SPEC.md

## 产品定位

`薄荷工坊 / Mint Atelier` 是一个桌面端 3 列 Web 工作台原型，用于呈现小红书内容创作流程。当前实现是 React + Vite 静态高保真界面，重点是产品结构、可见交互状态和工作台信息层级，不包含后端生成能力。

首屏必须保持生产力工具的清晰秩序：左侧导航栏、中间主工作区、右侧配置栏。不要把它改成营销落地页、品牌介绍页或普通卡片合集。

## 工作台结构

当前画布以 1440px 宽桌面端为基准，根布局为 3 列：

- 左侧导航栏：Logo、用户头像、主导航菜单、项目入口、设置入口。
- 中间主工作区：顶部欢迎/概览卡片、输入灵感、编辑草稿、效果预览、最近任务。
- 右侧配置栏：模型配置、Codex 参数、运行历史。

核心组件和信息层级应保持当前产品形态：

- `sidebar`：品牌、创作者资料、导航、项目列表、设置入口。
- `overview`：今日概览、关键指标、3D 笔记本/铅笔资产。
- `command`：输入灵感、导入素材、选择参考、字数计数、生成内容主按钮。
- `editor`：编辑草稿、分段标签、标题输入、正文编辑、AI 改写工具列。
- `preview`：小红书效果预览、作者、关注与分享操作、封面轮播角标与圆点、标题、正文摘要、话题标签、带图标的互动数据。
- `recent`：最近任务横向任务卡。
- `config-rail`：模型配置、Codex 参数、运行历史。

## 交互状态

当前 UI 使用本地 React state 驱动可见交互。至少保持：

- 左侧导航选中态。
- 编辑标签选中态。
- 文案生成模型和图片生成模型下拉可切换。
- 本地 CLI / 云端 API 运行方式分段控件可切换。
- Codex 参数控件可调整，包括 sandbox、approval、reasoning effort、verbosity 和 Web Search 开关。
- 输入灵感文本可编辑并更新计数。

新增控件必须属于工作台本身，不添加解释“如何使用界面”的可见说明文字，除非该文案本身就是产品界面的一部分。

## 右侧配置栏规则

右侧模型配置应支持文案生成模型和图片生成模型分开设置。每个生成通道都需要保留本地 CLI 与云端 API 两种运行方式，并使用当前黏土风格的分段控件、下拉选择和清晰选中态。

`Codex 参数` 区不使用通用采样参数作为主控件，应优先呈现 Codex CLI 可设置或可覆盖的运行语义，例如：

- `--sandbox`
- `--ask-for-approval`
- `--search`
- 通过 `-c key=value` 覆盖的推理强度、输出详略等配置

`运行历史` 保留近期任务状态，不展示本地资源面板。

## 不做和禁止恢复

除非产品方向明确改变，并同步更新 `docs/SPEC.md` 与 `docs/DESIGN.md`，不要：

- 恢复旧的 `采样参数`、`Temperature`、`Top P`、`重复惩罚`。
- 恢复旧的 `本地资源` 面板。
- 把工作台改成营销落地页。
- 把右侧配置栏改成通用 SaaS 设置面板。
- 引入真实发布、自动上传或外部平台操作能力。
