# DESIGN.md

## 视觉方向

设计风格是 `Pastel 3D Claymorphism Dashboard`：

- 主色使用马卡龙紫、粉、奶油白、浅蓝、浅黄、薄荷绿。
- 背景使用非常浅的紫粉到奶油渐变，不使用纯白背景。
- 卡片使用 24px 到 32px 大圆角，带柔和外阴影和轻微内高光，形成 3D 黏土凸起感。
- 按钮使用胶囊形状和轻微立体感，主按钮保持粉紫渐变。
- 图标保持圆润 3D soft icon / 软糖质感，不要替换成普通线性图标。
- 整体应该像精致的 3D 玩具工作台，但不能幼稚、混乱或牺牲可读性。

禁止方向：

- 深色科技风。
- 玻璃拟态。
- 极简黑白风。
- 营销落地页 hero。
- 普通线性图标替代 3D soft icon。
- 一味堆卡片导致内容拥挤或层级不清。

## 布局规范

页面必须支持上下滚动。外层布局不能使用会裁切内容的 `overflow: hidden`。关键约束是：

- `body` 允许 `overflow-x: auto` 和 `overflow-y: auto`。
- `.app-shell` 使用 `min-height` 而不是固定 `height`。
- `.app-shell` 保持 `overflow: visible`。
- 中间 `.creative-grid`、`.editor`、`.preview` 需要足够的最小高度，避免编辑区、预览区和最近任务被切割、剪裁或遮挡。
- `.preview` 内的小红书 `.post-card` 需要按内容自适应高度，互动数据 footer 必须留在卡片内部，不能被固定高度挤出或遮挡。
- 中间最近任务区域使用内容驱动的最小高度，任务卡和状态控件不能被底部边界压住。

修改布局时必须在 1440x900 和较矮视口中检查：

- 中间内容不被裁切。
- 底部最近任务和左侧设置入口可滚动访问。
- 右侧模型配置、Codex 参数和运行历史完整可见或可滚动访问。
- 文本、按钮、卡片互不重叠。

## 组件视觉语言

核心组件应保持当前 Pastel 3D Claymorphism 语言：

- 面板使用大圆角、柔和外阴影、轻微内高光和浅色渐变。
- 按钮使用胶囊形状、清晰选中态和轻微凸起感。
- 分段控件、下拉选择、开关和任务状态都要维持黏土风格，不改成普通表单控件外观。
- 生产力工具的信息层级必须清晰，不能因为装饰导致可读性下降。
- 不要使用可见说明文字解释界面功能、键盘快捷键或视觉元素，除非该文案本身属于产品界面。

如果新增控件，应使用项目现有组件语言：大圆角、柔和阴影、胶囊按钮、清晰选中态和适度留白。
